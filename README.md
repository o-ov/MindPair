# MindPair

**双 AI 协作设计系统** — 两个 AI 角色围绕任务目标轮流设计、质疑、优化，直至达成共识。

---

## 简介

MindPair 是一款基于双大语言模型的协作设计工具。用户提出任务目标，两个 AI 分别扮演不同角色，以交替发言的方式推进设计讨论：

- **AI A** 提出方案 / 设计思路
- **AI B** 评估、质疑、提出改进意见
- AI A 基于反馈继续优化
- 循环迭代，直到双方达成一致

**适用场景**：系统架构设计、产品方案设计、技术方案评审等需要多角度推敲的任务。

---

## 核心概念

| 概念 | 说明 |
|------|------|
| **Session（协作会话）** | 一次完整的多轮对话任务 |
| **角色 A / 角色 B** | 可独立配置身份、性格、专业领域的 AI |
| **Round（轮次）** | 一次 A→B 或 B→A 的完整交互 |
| **共识** | 双方均认可当前方案，对话结束 |

## 快速开始

### 环境要求

- Python 3.11+
- Node.js 18+

### 安装

```bash
# 后端
cd backend
pip install -r requirements.txt

# 前端
cd frontend
npm install
```

### 配置

创建 `backend/.env`：

```env
MINIMAX_API_KEY=your_minimax_key
DEEPSEEK_API_KEY=your_deepseek_key
```

### 运行

```bash
# 后端
cd backend
uvicorn main:app --reload --port 8000

# 前端 (另一个终端)
cd frontend
npm run dev
```

访问 `http://localhost:5173`

## 角色配置

### 预设角色：产品大神张小龙

两个 AI 扮演同一角色"产品大神张小龙"，但由不同模型驱动。相同的角色灵魂 + 不同的模型特质 = 差异化的思维碰撞。

| 角色 | 模型 | 定位 |
|------|------|------|
| **AI A** | MiniMax M2.7-highspeed | 张小龙式产品思维，简洁、克制、注重产品本质 |
| **AI B** | DeepSeek V4 Flash | 张小龙式产品思维，深度推理、结构化、注重逻辑严密 |

**模型特质差异：**

- **MiniMax**：更直接、简洁、克制，贴近张小龙"少就是多"的理念
- **DeepSeek**：推理更深透、论证更严谨，擅长拆解复杂问题

两者对同一设计问题的思考角度会有微妙差异，最终在碰撞中收敛到更优方案。

### 自定义角色

在「设置」中可自定义角色名称、系统提示词、模型参数（温度、最大 tokens 等）。
